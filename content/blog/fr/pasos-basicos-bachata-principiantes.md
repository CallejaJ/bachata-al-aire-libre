Vous voulez apprendre à danser la bachata mais vous ne savez pas par où commencer ? Ne vous inquiétez pas, nous y sommes tous passés. Dans ce tutoriel, je vais vous enseigner les pas fondamentaux dont vous avez besoin pour commencer à danser avec confiance.

## Qu'est-ce que la Bachata ?

La bachata est une **danse sociale dominicaine** caractérisée par son rythme romantique et ses mouvements de hanches sensuels. Elle se danse en couple et c'est l'une des danses latines les plus populaires au monde.

### Caractéristiques principales :

- **Rythme** : 4 temps avec un « tap » sur le 4

- **Mouvement** : Latéral ou en carré

- **Style** : Romantique et sensuel

- **Musique** : Guitares, bongos et paroles d'amour

## Avant de Commencer : La Préparation

### La Posture Correcte

1. **Dos droit** mais détendu

2. **Genoux légèrement fléchis**

3. **Poids sur les plantes des pieds**

4. **Épaules détendues en arrière**

5. **Regard vers l'avant** (pas vers le sol)

### Conseil Pro :

> La posture représente 50 % de la danse. Une bonne posture fait paraître n'importe quel pas meilleur.

## Pas 1 : Le Pas de Base Latéral (En Individuel)

C'est le pas le plus fondamental. Pratiquez-le jusqu'à ce qu'il soit automatique.

### Pour le Leader (généralement l'homme) :

**Temps 1** : Pas latéral gauche avec le pied gauche
**Temps 2** : Le pied droit rejoint le gauche
**Temps 3** : Pas latéral gauche avec le pied gauche
**Temps 4** : Tap avec le pied droit (touche le sol sans transférer le poids) + mouvement de hanche

**Temps 5** : Pas latéral droit avec le pied droit
**Temps 6** : Le pied gauche rejoint le droit
**Temps 7** : Pas latéral droit avec le pied droit
**Temps 8** : Tap avec le pied gauche + mouvement de hanche

### Pour le Suiveur (généralement la femme) :

C'est exactement la même chose mais **vous commencez avec le pied droit** (en miroir du leader).

**Temps 1** : Pas latéral droit avec le pied droit
**Temps 2** : Le pied gauche rejoint le droit
**Temps 3** : Pas latéral droit avec le pied droit
**Temps 4** : Tap avec le pied gauche + hanche

**Temps 5** : Pas latéral gauche avec le pied gauche
**Temps 6** : Le pied droit rejoint le gauche
**Temps 7** : Pas latéral gauche avec le pied gauche
**Temps 8** : Tap avec le pied droit + hanche

### Pratique :

Consacrez **au moins 10 minutes** uniquement à ce pas avec une musique lente. Comptez à voix haute : « 1, 2, 3, tap - 5, 6, 7, tap »

## Pas 2 : Le Mouvement de Hanche

Le mouvement de hanche est ce qui donne du « piquant » à la bachata.

### Technique :

1. Sur le temps 4 (le tap), **fléchissez légèrement le genou** de la jambe d'appui

2. Cela fera que votre hanche se déplacera **naturellement** de ce côté

3. **Ne forcez pas** le mouvement - il doit être doux et naturel

4. La hanche « tombe » du côté de la jambe d'appui

### Erreur Courante :

➖ Bouger la hanche avec la partie supérieure du corps

🎶 Le mouvement vient des genoux, pas du torse

## Pas 3 : Le Pas de Base en Couple (Position Fermée)

Maintenant, nous allons appliquer le pas de base avec votre partenaire.

### Position de Prise :

**Leader :**

- Main droite dans le dos du suiveur (omoplate)

- Main gauche tient la main droite du suiveur

- Coudes à 90 degrés

- Bras fermes mais pas rigides

**Suiveur :**

- Main gauche sur l'épaule/biceps du leader

- Main droite dans la main gauche du leader

- Maintenez votre propre poids (ne vous appuyez pas sur votre partenaire)

### Exécution du Pas de Base :

1. Le leader commence avec le pied gauche, le suiveur avec le droit

2. Ils se déplacent **en miroir** (quand le leader va vers sa gauche, le suiveur va vers sa droite)

3. Maintenez un **contact visuel** occasionnel (ne regardez pas les pieds)

4. Respirez et détendez-vous

## Pas 4 : Votre Premier Tour (Tour à Droite pour le Suiveur)

Une fois que vous maîtrisez le pas de base, c'est l'heure de votre premier tour.

### Depuis la Position Fermée :

**Temps 1-3** : Pas de base normal
**Temps 4** : Le leader lève son bras gauche (signal de tour)

**Temps 5-7** : Le suiveur fait un tour de 360° vers sa droite tout en faisant le pas de base
**Temps 8** : Termine le tour face au leader

### Conseils pour le Tour :

- **Suiveur** : Maintenez votre pas de base pendant que vous tournez (ne bloquez pas les pieds)

- **Leader** : Levez le bras suffisamment mais sans forcer

- **Les deux** : Le tour est fluide, pas précipité

- **Spotting** : Fixez un point du regard pour ne pas avoir le vertige

## Erreurs Courantes et Comment les Corriger

### Erreur 1 : Regarder ses pieds

**Solution** : Pratiquez devant un miroir. Comptez les temps à voix haute.

### Erreur 2 : Être tendu

**Solution** : Respirez profondément. Rappelez-vous que c'est pour s'amuser, pas un examen.

### Erreur 3 : Ne pas écouter la musique

**Solution** : Écoutez de la bachata dans votre temps libre. Identifiez les temps.

### Erreur 4 : Aller trop vite

**Solution** : Pratiquez d'abord avec une musique lente. La vitesse vient toute seule.

## Chansons Recommandées pour Pratiquer

Voici des chansons avec un **rythme clair et un tempo lent**, parfaites pour les débutants :

1. **« Obsesión »** - Aventura (classique et lente)

2. **« Dile al Amor »** - Aventura (très claire)

3. **« Propuesta Indecente »** - Romeo Santos (tempo moyen)

4. **« Bella y Sensual »** - Romeo Santos & Daddy Yankee (plus rapide)

## Routine de Pratique Hebdomadaire

Pour progresser rapidement, je vous recommande :

**Jour 1-2** : 20 min de pas de base latéral individuel

**Jour 3-4** : 20 min de pas de base en couple

**Jour 5-6** : 15 min de tours + 10 min de freestyle

**Jour 7** : Sortez danser en soirée sociale !

## Niveau Suivant : Que Faut-il Apprendre Ensuite ?

Une fois ces fondamentaux maîtrisés :

- Tour à gauche

- Tour complet (enchufla)

- Changements de main

- Pas en miroir

- Mouvements de torse (body rolls)

## Conclusion

La bachata ne s'apprend pas en un jour, mais avec ces pas de base vous avez tout ce qu'il faut pour commencer. Rappelez-vous :

1. **La pratique fait le maître** : 20 minutes par jour valent mieux que 2 heures une fois par semaine

2. **Ne vous comparez pas** : Chacun apprend à son rythme

3. **Amusez-vous** : Si vous n'en profitez pas, c'est que vous ne le faites pas bien

4. **Soyez patient** : Les bons danseurs ont des années de pratique
